# Soft Compass icon

Concept 01 from the LifeOps gold icon exploration. Generated with ImageGen CLI using the GPT Image 2 model. Browser Mods uses the original 1024 × 1024 composition and its graphite background.

The reusable master is in [Mods Shared](https://github.com/DovieW/dovies-mods-shared/blob/66b3e7f/design/brand/lifeops-soft-compass.png). Copy the master to `assets/icon.png` and run `npm run icons` to regenerate the packaged sizes.

## Prompt

Create one original gold brand glyph for LifeOps / DovieW, a shared icon across custom browser mods and desktop tools. LifeOps values person-centered coordination, continuity over time, visible evidence, and control. Flat, vector-like brand exploration. Use a precisely uniform near-black graphite background (#14171D), with one centered isolated glyph occupying about 64% of the square width and height and ample clear padding. Gold only within the symbol: pale honey, antique gold, and restrained amber as appropriate. Design for a browser favicon: strong single silhouette or a few thick forms, crisp antialiased edges and generous negative spaces. Show one icon with straight-on framing, no words, letters unless requested in the concept, labels, border, tile, mockup, embossing, cast shadows, glow, scattered details, texture, watermark or extra objects. A soft four-point glint, stretched slightly upward, with deeply scooped sides and rounded point tips. Use a broad antique-gold to pale-honey gradient on a single clean face. This is the most direct exploration of a calm four-point silhouette.
