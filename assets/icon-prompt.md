# Soft Compass icon

Soft Compass started as concept 01 from the LifeOps gold icon exploration. Browser Mods uses the **02 · Modal with border** revision, edited with ImageGen and resized to 1024 × 1024. The corners outside the circle are transparent.

The reusable master is in [Mods Shared](https://github.com/DovieW/dovies-mods-shared/blob/2584fb1/design/brand/lifeops-soft-compass.png). Copy the master to `assets/icon.png` and run `npm run icons` to regenerate the packaged sizes.

## Prompt

Keep the centered gold four-point symbol, its rounded tips, and its warm gradient. Use an opaque GitHub Dark Default modal circle based on #161b22 and a thin #30363d outline. Keep the area outside the circle transparent.
